# **App Name**: MobiShop Showcase

## Core Features:

- Portfolio Product Display: Display a curated list of mobile products with an emphasis on high-quality images and key specifications, reflecting a portfolio-style presentation.
- Product Filtering and Search: Provide users the ability to filter products based on brand, price range, and features (e.g., screen size, camera resolution), and to search by keyword.
- Wishlist Functionality: Allow users to add items to a wishlist for later purchase, saving their preferences without requiring immediate commitment.
- Detailed Product Pages: Present each product on its own page with detailed specifications, multiple high-resolution images, and customer reviews to simulate an in-depth, portfolio-like presentation.
- Contact form submission: Contact form submission via email.
- AI Product Recommendations: Suggest related products using a tool which learns from browsing behavior. Offers a way to present more options, driven by generative AI.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and professionalism in the mobile shop's online presence.
- Background color: Light blue (#E8EAF6) to ensure a clean and modern aesthetic that emphasizes product images.
- Accent color: Vibrant orange (#FF5722) to draw attention to key actions and highlights, encouraging user interaction.
- Body and headline font: 'Inter' (sans-serif) for a clean, modern and readable interface. It works well for both headlines and body text.
- Employ a grid-based layout to present products in a visually appealing and organized manner.
- Use a consistent set of icons for navigation and key features (e.g., search, wishlist), to guide users intuitively through the site.
- Implement subtle animations (e.g., fade-ins, transitions) to enhance the user experience and add a touch of modern sophistication.
